# libbitcoin-database

The store: memory-mapped tables, and the queries over them.

Documentation is at [libbitcoin.org/lib/database](https://libbitcoin.org/lib/database.html).

Download [Bitcoin Server (`bs`)](https://libbitcoin.org/download/index.html).
